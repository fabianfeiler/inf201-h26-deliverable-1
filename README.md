# INF201 H26 Deliverable 1

Analysis of weather data from Ås (SN17850) using the MET Norway Frost API.

## Setup

1. Create a virtual environment and install dependencies:
   `pip install -r requirements.txt`
2. Create a user at frost.met.no and save your client ID in
   `~/frost_client_id.txt` (outside this repository).
3. Open `deliverable_1.ipynb` and run all cells.
